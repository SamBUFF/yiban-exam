# 答案匹配算法与歧义处理

## 为什么不能按字母点

同一道题在不同组卷里 A/B/C/D 位置不同（实测：第 1 套与第 2 套的 `考试作弊处分` 选项分别落在 B 和 C）。
**所有定位都按选项文本内容，绝不按下标。**

## 算法（`inject.js` 的 `Y.pickIndex`）

```js
norm(s) = s
  .replace(/^[A-DＡ-Ｄ]\s*[.．、]\s*/, '')     // 剥选项前缀 "A. "
  .replace(/[（(]/g, '(').replace(/[）)]/g, ')')  // 全角括号统一
  .replace(/[\s，,。.；;：:！!？?、·・\-—_—~～"'""'']/g, '')  // 去全部标点空白

pickIndex(key, lis):
  1. norm(选项) === norm(key)         → 命中（要求候选唯一）
  2. norm(选项).includes(norm(key))   → 命中（要求候选唯一）
  3. 否则 MISS
```

**刻意不做「关键词包含选项文本」的反向匹配。** 这是初版最大的 bug 来源：

| 关键词 | 被误命中的选项 | 正确选项 |
|---|---|---|
| `警告处分` | `严重警告处分`（因为 `"严重警告处分".includes("警告处分")` 为真） | `警告处分` |
| `III级` | `II级` | `III级` |

反向匹配在长关键词（一句完整的话）时才偶尔有用，但收益远小于风险 —— 需要时请改用完整长句。

## status 语义

| status | 含义 | 处理 |
|---|---|---|
| `clicked` | 已点中 | 正常 |
| `already` | 之前已选中（幂等重跑） | 正常 |
| `NOANS` | 该题号在 answers 里没有 | 补答案 |
| `NOOPT` | 选项列表没找到 | 页面还没渲染完 / 结构变了 → 检查 `state()` |
| `MISS` | 所有选项都不含关键词 | **人工介入** |
| `AMB:1,3` | 多个候选，不敢猜 | **人工介入** |
| `NAVFAIL` | 翻页后题号没变 | 检查页面是否卡住、是否有弹窗 |
| `NONAV` | 找不到「下一题」按钮 | 可能已在末题，或页面结构变了 |

## 歧义处理决策树

```
MISS / AMB
├─ 选项原文里其实有同义但不同措辞的？
│    → 换一个更短的、确实出现在某个选项里的连续子串
├─ 两个选项高度相似（如「只安排一次补考机会」 vs 「只安排一次补考机会，补考不及格只能重修」）？
│    → 关键词写**完整长句**，让精确匹配唯一命中
├─ 关键词太短（III级 / 6个月 / 10%）？
│    → 补上下文：写「预警 III级」「考察期 6个月」；或直接 --set Q --index N
└─ 都不行
     → --set Q --index N 按下标点（这是唯一按下标的场景，用前必须肉眼核对选项原文）
```

## 实测踩过的具体案例

| 题 | 关键词 | 症状 | 解法 |
|---|---|---|---|
| 「受警告处分考察期」 | `警告处分` | 选中了 `严重警告处分` | 关键词改 `警告处分，考察期` 或按下标 |
| 「学业预警 III 级」 | `III级` | 选中了 `II级` | 关键词补足为 `三级预警` 或整句 |
| 「补考安排」 | `只安排一次补考机会` | 精确匹配命中了更短的 D 项 | 改用完整句 `只安排一次补考机会，补考不及格只能重修` |

## 选项文本里常见的排版差异（`norm` 已处理）

- 全角括号 `（一）` vs 半角 `(一)`
- 顿号 / 逗号 / 句号的中英混用
- 空格、`\u3000` 全角空格、`\xa0` 不换行空格
- 破折号 `—` / `–` / `-` 混用
- 引号 `"…"` / `“…”` / `「…」`

## 复验要求

作答完成后**必须**跑全量复验（`auto_answer.py --verify`），确认除标 `推断` 的题外每题 `sel` 非空。
平台若「禁止查卷」，交卷后就再也无法逐题核对 —— 复验是最后一道保险。
