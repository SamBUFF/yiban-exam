# 一手依据的建立与检索

答题质量的上限就是依据文本的质量。这一步做扎实，后面全是机械劳动。

## 1. docx → 纯文本

```bash
"$PY" "$HOME/.workbuddy/skills/yiban-exam/scripts/docx_to_text.py" \
      "~/Downloads/学生手册（1）.docx" 依据.txt
```

原理：docx 就是个 zip，文本全在 `word/document.xml`。按 `</w:p>` 切段、抓每段的 `<w:t>`、
`<w:br/>` 转成换行，就是「段落顺序完全一致」的纯文本。表格单元格本身就是 `w:p`，天然排在文档流里，不用特殊处理。

实测（广东工程职业技术学院学生手册，2.9 MB）：**产出 5324 个非空段落**。

### 为什么不用文档类工具

| 尝试 | 结果 |
|---|---|
| `Read` 直接读 docx | `Cannot display content of binary file` |
| `doc_resolve_document_structure` | `document is not open`（即使 `get_pool_status` 显示在池中） |
| `doc_get_document_content` | 工具根本不存在（`edsdk.py schema` 报未找到） |
| `doc_to_image`（中文路径） | `file not found` |
| `doc_to_image`（复制成英文名后） | `COS upload failed ... upload_to_cos.py: No such file or directory` |

结论：**直接 Python 解 zip 最可靠**，不依赖任何文档服务。

## 1b. pdf → 纯文本

法规原文、新闻/党史文章、公告这类资料基本都是 PDF，docx 那套解 zip 的路子完全不适用。

```bash
"$PY" "$SK/scripts/pdf_to_text.py" 依据.txt "国旗法.pdf" "国徽法.pdf" "国防教育法.pdf"
```

用 `pypdf`（托管 Python 自带）：逐页 `extract_text()`，逐行 strip 后只保留非空行。
多个文件之间插入 `### FILE: <文件名>.pdf` 分隔行 —— **分隔行本身占一个行号**，引用时不要跳开。

实测（2026-10-05，8 份法规/党史 PDF：国旗法 + 国徽法 + 国防教育法 + 国防法 + 3 篇党史/学习文章）：产出 1166 行，
法规正文提取质量很高，条款原句可以直接拿来当依据（例：`L14 第二条 中华人民共和国国旗是五星红旗。`）。

| 情况 | 表现 | 处理 |
|---|---|---|
| 正常文字版 PDF | 每页提取出完整段落 | 直接用 |
| 扫描件 / 图片页 | `text_lines=0`，脚本会提示 | 只能 OCR；否则改标 `推断` |
| 加密 PDF | `reader.is_encrypted` | 脚本会试空密码；失败就换来源 |

**多份资料要不要合一个文件**：

- 多份**不同**资料 → **建议合**（`pdf_to_text.py` 本来就是多文件入参）。这样一份 `依据.txt` 覆盖整套考试范围，跨资料交叉印证（"国旗法管到哪、国防教育法管到哪"）很方便，`### FILE:` 分隔行保证能定位来源。
- **同一份资料的两个版本 → 绝不能合**。行号会串，引用 `L4545` 时无法判断是哪一版，复核直接失效。换新版本时生成新的 txt。

## 2. 检索

```bash
"$PY" "$SK/scripts/grep_evidence.py" 依据.txt 抄袭 夹带 -c 2
```

多关键词默认 **AND**（都出现才算命中），`-o` 切换为 OR。
`-r A B` 直接打印行号区间原文（复核已知条款时用）。
`-l N` 打印第 N 行及上下文。

### 检索策略

1. 从题干里挑 **2–3 个一定会一起出现的实词**（名词优先，别用"下列""正确"这类虚词）。
2. 命中后**读上下文，不要只看命中行** —— 条款常跨 2–3 段，把表头 / 前提条件一起读到。
3. 数字类题目（6个月 / 10% / 8000元）直接搜数字 + 单位，往往一击即中。
4. 搜不到时换同义词：`警告` → `处分`、`撤销` → `注销`、`补考` → `重（补）修`。手册用词与题干措辞经常不一致。

## 3. 依据记录规范

答案表必须带「一行号一原句」，格式：

| 题号 | 题目摘要 | 所选答案 | 依据 |
|---|---|---|---|
| 23 | 考试夹带资料的处理 | 警告处分 | L1580 抄袭夹带=考试作弊，给予警告处分 |
| 44 | 优秀毕业生奖学金比例 | 6% | L4545 优秀毕业生按毕业生总数 5%（三年制）/ 6%（两年制） |

行号是 `依据.txt` 里的行号（= 段号）。有了它，任何一个答案事后都能 30 秒内复核。

## 4. 已知无解的情况

| 情况 | 处理 |
|---|---|
| 条款是**图片**（如"申请加入学生机构的流程"是流程图） | 无法 OCR → 按流程逻辑推断，**必须**在交付时单独列出并说明原因 |
| 手册完全没有对应内容 | 同上，标 `推断` |
| 题干本身语义有歧义 | 标 `推断` + 写出两种解读 |

**绝不静默推断。** 交付时要能一句话说清：哪几题是查不到的、为什么、按什么逻辑定的。

## 5. 复用已有的依据文本

同一份资料（如学生手册）会被反复用。首次生成后留在工作区即可，后续直接 `grep_evidence.py` 检索，不必重新解析。
若后续换了一份新资料（新版手册、另一门课的复习资料），重新生成一份新 txt，**不要**把两份**同一文档的不同版本**混在一个文件里（行号会串）。
**多份不同的**资料则相反，鼓励合进同一个 `依据.txt`（用 `### FILE:` 分隔），便于统一检索与交叉引用。

## 6. 依据覆盖不到的题怎么办

考卷常混入资料范围外的题（例：2026-10-05 那套「国旗 / 军训」卷，10 题里有 2 题考的是解放军
**队列条令**动作要领——立正两脚尖分开约 60 度、稍息左脚伸出约全脚三分之二——而用户给的 8 份
PDF 全是法律法规，一条都对不上）。

处理原则：

1. **先把"资料内"和"资料外"分开**。资料内的一律标行号；资料外的**一题都不许伪装成有依据**。
2. 资料外的题，若属**常识 / 公开标准**（队列条令、法定日期、基本常识），可以按公认答案作答，但必须在答案表里逐题标 `⚠️ 推断`，并写清「按什么依据推的、为什么资料里没有」。
3. 交付时单独列一节说明，让用户能一眼决定要不要改。**绝不静默推断。**
